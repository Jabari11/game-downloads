# Game downloads

Builds are attached to [Releases](https://github.com/Jabari11/game-downloads/releases), not committed here (they are larger than GitHub's 100 MB file limit).

## Solar Swim (Windows playtest)

[Download the latest build](https://github.com/Jabari11/game-downloads/releases/latest/download/SolarSwim-playtest.zip)

Unzip it anywhere and run `SolarSwim/SolarSwim.exe`. Windows may warn that the app is unrecognized: choose **More info → Run anyway**. Controls are in the `README.txt` inside the zip.
